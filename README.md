## 📌 Featured Project

### 🏠 Airbnb End-to-End Data Engineering Pipeline

An end-to-end data engineering project demonstrating modern cloud data warehousing and transformation patterns using **AWS S3, Snowflake and dbt**.

**Architecture**

```text
CSV Source Data
      ↓
    AWS S3
      ↓
Snowflake Staging
      ↓
   Bronze Layer
      ↓
   Silver Layer
      ↓
    Gold Layer
      ↓
Analytics-Ready Data
```

**Key engineering patterns**

- Medallion architecture: Bronze → Silver → Gold
- Incremental dbt models
- Slowly Changing Dimensions (SCD Type 2)
- dbt snapshots and data lineage
- Reusable Jinja/macros
- Data quality and validation tests
- Dimensional and One Big Table (OBT) modeling
- Snowflake schema organization
